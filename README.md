# Bad Habit Tracker

A web-based habit tracking application designed to help users monitor bad habits and understand how much time they may be losing through them.

## 📋 About the Project

**Bad Habit Tracker** is a web-based productivity application that helps users track and analyze habits that consume their time.

This project was originally created to fulfill the final project requirement of **RevoU CodingCamp**, which required participants to build a mini to-do list project.

Rather than creating a conventional to-do list, I wanted to explore a different perspective:

> **How much time can our habits consume without us realizing it?**

Because of this, the concept was expanded into a habit tracking application focused on helping users become more aware of their habits and the time associated with them.

The application provides a responsive interface, interactive data visualization, and features designed to help users monitor their habits and improve productivity.

## 🎯 Project Goals

The main goals of Bad Habit Tracker are to:

* Track habits that may negatively affect productivity.
* Help users become more aware of how frequently habits occur.
* Estimate and visualize the amount of time spent on tracked habits.
* Present habit data in an easy-to-understand format.
* Encourage users to reflect on their daily routines.
* Practice building an interactive and responsive web application.

## ✨ Features

### 📊 Habit Tracking

Users can record and monitor their habits over time.

Each habit can contain information that helps the user understand its frequency and estimated time consumption.

### ⏱️ Time Tracking

The application helps users estimate how much time is spent on tracked habits.

This allows users to see the potential amount of time lost through repeated habits.

### 📈 Data Visualization

Habit data is presented visually to make patterns easier to understand.

Visualizations can help users identify:

* Frequently repeated habits
* Time-consuming habits
* Changes in habits over time
* Overall time consumption

### 📱 Responsive Design

The interface is designed to work across different screen sizes, including:

* Desktop
* Tablet
* Mobile

### 🧠 Self-Awareness

Rather than simply telling users to stop a habit, the application focuses on providing information that can help users understand their own behavior.

The goal is to turn habit tracking into a tool for self-reflection and productivity improvement.

Bad Habit Tracker is a web-based application and can be run locally using a modern web browser.

2. Open the project folder.
3. Open `index.html` in a modern browser.
